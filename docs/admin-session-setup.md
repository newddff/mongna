# 팬페이지 공통 관리자 로그인

홈·캘린더·몽무위키·노래책·업보는 같은 서버 관리자 세션을 사용합니다. 같은 브라우저와 같은 주소에서 한 번 로그인하면 다른 페이지에서도 관리자 기능을 사용할 수 있습니다. 로그아웃은 서버 쿠키를 지우며 다른 탭도 서버 세션을 다시 확인합니다.

## 세션과 설정

- `ADMIN_PASSWORD`: 기존 관리자 비밀번호.
- `ADMIN_SESSION_SECRET`: 32자 이상의 무작위 비밀값. Production과 Preview 각각 설정해야 합니다.
- 로그인은 `POST /api/auth`, 상태 확인은 `GET /api/auth/session`, 로그아웃은 `DELETE /api/auth/session`을 사용합니다.
- 인증 쿠키는 HttpOnly·Secure·SameSite=Lax·Path=/이며 유효기간은 12시간입니다.
- 공통 클라이언트 `public/admin-session.js`는 로그인 후 실제 서버 세션까지 확인합니다. 비밀값이 미설정되어 쿠키를 만들지 못하면 관리자 화면을 활성화하지 않습니다.
- React 화면은 `src/lib/use-admin-session.ts`, 정적 HTML 화면은 같은 공통 클라이언트 모듈을 가져와 사용합니다.
- 페이지 진입·탭 복귀·주기적 확인과 다른 탭의 로그인/로그아웃 신호로 상태를 갱신합니다. 브라우저 저장소에는 인증 정보가 아닌 갱신 신호만 기록합니다.
- 일시적인 통신 실패·서버 오류·잘못된 응답은 마지막으로 확인된 화면 상태와 편집 내용을 유지합니다. 다음 주기/탭 복귀에 다시 확인하며, 서버가 `authenticated: false` 또는 401/403을 반환하면 관리자 모드를 해제합니다. 최초 인증과 로그인 직후 확인은 성공해야 하며, 저장 API는 매 요청에서 실제 세션을 검증합니다. 12시간 만료는 연장하지 않습니다.
- 예전 `mongna_secure_admin_v2` 값은 인증 근거로 사용하지 않습니다. 저장 API의 서버 세션 검증은 계속 적용됩니다.
- 서로 다른 브라우저, 시크릿 창, Production과 Preview 등 서로 다른 주소는 각자 로그인해야 합니다.

## 확인 방법

1. 홈에서 관리자 로그인 후 캘린더·몽무위키·노래책·업보로 이동해 관리자 버튼이 표시되는지 확인합니다.
2. 노래책과 업보를 다른 탭에 열고 한쪽에서 로그인/로그아웃하여 다른 탭도 바뀌는지 확인합니다.
3. 어느 페이지에서 로그아웃해도 다른 페이지를 새로고침하면 관리자 기능이 표시되지 않아야 합니다.
4. 로그인 없이 로컬 저장소의 예전 관리자 표시만 바꿔도 관리자 기능이 켜지지 않아야 합니다.
