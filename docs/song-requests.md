# 몽나 신청곡

1. 방송 중 기존 SOOP 채팅 연동과 같은 사이트의 `/streamer/song-requests`에 들어간다. 채팅 게임룸 상단에서도 열 수 있다.
2. 몽나 SOOP 계정으로 연결하고, ‘채팅 접수 열기’를 누른다.
3. 시청자는 `!신청곡 아이유 - 밤편지` 또는 `!신청곡 https://youtu.be/BzYnNdJhZQw`를 입력한다.
4. 첫 곡이 들어오면 ‘재생 시작’을 누른다. 이후 완료된 곡은 다음 곡으로 넘어간다. 브라우저가 자동 재생을 막으면 ‘재생’을 다시 누른다. 채팅 접수는 기본으로 꺼져 있다. ‘채팅 접수 닫기’를 누르면 새 채팅 신청만 받지 않으며, 이미 들어온 곡은 계속 순서대로 재생된다. 방송용 목록 표시는 채팅 접수와 별개다. 오버레이에는 현재 곡, 대기 순서대로 다음 3곡, 그 외 대기곡 수가 표시된다.
5. OBS에서 재생 탭이 들어 있는 브라우저의 소리를 캡처한다. 곡 정보만 띄울 경우 상단의 오버레이를 **같은 브라우저 프로필**에서 별도 창으로 열어 OBS 창 캡처를 사용한다. OBS 브라우저 소스는 별도 브라우저라 이 오버레이와 직접 동기화되지 않는다.

유튜브 링크 신청은 추가 키 없이 작동한다. 가수·곡명 검색은 Google Cloud에서 YouTube Data API v3를 활성화한 뒤 배포 환경에 서버용 `YOUTUBE_DATA_API_KEY`를 추가해야 한다. 이미 서버용 `YOUTUBE_API_KEY`가 설정되어 있다면 그대로 사용할 수 있다. 키는 해당 API로 제한하고 `NEXT_PUBLIC_` 변수로 설정하지 않는다. 영상의 임베드 제한에 따라 재생이 실패할 수 있다. 방송에는 재생 권한이 있는 곡만 사용한다.

대기열은 켜둔 플레이어 탭에만 유지된다. 방송 중에는 재생 탭을 한 개만 열고 새로고침하지 않는다. 같은 영상의 중복 접수를 막으며, 시청자당 한 번에 한 곡, 30초 간격, 전체 20곡으로 제한한다.
