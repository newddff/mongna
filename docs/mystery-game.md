# 달빛 탐정 사무소

`/streamer/mystery`에서 「비 내리는 저택, 마지막 초대」를 플레이한다. 팬페이지 미니게임 목록과 기존 스트리머 게임룸에서 이동할 수 있다. 기존 게임 및 API는 변경하지 않는다.

몽나가 현장 조사, 질문, 증거 제시와 최종 추리를 직접 진행한다. 투표 패널을 열지 않으면 채팅 SDK와 세션 API를 요청하지 않는다. 투표를 열면 기존 `useSoopChat`과 몽나 계정 제한을 재사용한다. 최초 인증 후 복귀 경로는 `/streamer/mystery`이며 기존 공용 callback을 사용한다. 새 API Scope나 환경변수는 필요 없다.

투표는 30초 동안 `!투표 1`부터 `!투표 4`까지 받는다. 사용자당 첫 유효 표만 집계하고 마감 시각 이후 표는 거절한다. 호스트가 결과를 공개하기 전까지 득표 수는 숨긴다. 투표 결과는 조사·추리 상태를 바꾸지 않는다. 연결 중단 시 집계를 마감하며, 패널을 닫으면 SDK도 정리한다.

진행, 조사한 증거, 증언, 추리 메모는 해당 브라우저의 localStorage에 저장한다. 개인 진행을 서버에 저장하거나 다른 기기로 동기화하지 않는다. 스토리의 정답을 포함한 데이터는 클라이언트에 있으므로 방송 시청자의 개발자 도구를 통한 스포일러 확인을 방지하는 구조는 아니다.

## 시나리오 반영과 수정

사용자가 제공한 Claude 시나리오를 `src/lib/mystery/scenario.json`에 반영했다. 대사와 핵심 사건을 유지하고 아래 논리를 정리했다.

- 노크 무응답만으로 사망 시각을 단정하지 않고 정각 직후 즉시 시신을 확인하는 장면으로 연결했다.
- 정전 중 카드로 외부에서 들어갈 수 없는 규칙과 내부 비상퇴실, 외부 비상 열쇠를 구분했다. 비상 열쇠는 피해자의 서랍에서 획득하며 사용 기록이 남는다.
- 수장고 입장 권한자가 누구인지 플레이어가 읽는 안내문에도 공개했다.
- 서류철의 원본 번호와 자필 서명을 오프닝과 발견 장면 양쪽에서 확인한다.
- 두 사람의 테라스 합류 시각이 서로 다르게 서술되던 대사를 타임라인과 일치시켰다.
- 몽나의 감시 범위와 서재에서 현관까지 2분 이상 걸린다는 사실을 오프닝에서 공개했다.
- 최종 추리는 핵심 단서 3개뿐 아니라 마지막 증거 제시까지 완료해야 열린다. 장소 개방 규칙은 case.ts 한곳에서 판정한다.

## 그림

기본 이미지 생성 도구로 생성한 두 장의 아틀라스를 WebP로 변환하여 저장했다. 배경은 `public/mystery/rooms.webp`, 초상화는 `public/mystery/portraits.webp`다. CSS의 2×2 영역으로 네 장소와 네 인물을 각각 표시한다. 배경의 개략적인 소품 묘사는 분위기용이며, 단서의 시간·문구·세부 위치는 조사 기록으로 판정한다. 잔혹한 시신 이미지나 점프스케어는 없다.

배경 프롬프트: 비 오는 7월 밤 한국 산속 수집가 저택, 서재·현관과 응접실·후면 테라스와 차고·지하 수장고 복도의 2×2 아틀라스. 동일한 회보라색과 나무, 호박색 조명. 인물·문자·시신·스포일러 물증 없이 각 장소를 독립된 패널로 구성.

인물 프롬프트: 서도현 44세 베이지 재킷, 강태오 56세 안경과 남색 정장, 오세린 31세 짧은 머리와 세이지색 카디건, 문하윤 38세 낮게 묶은 머리와 차콜색 재킷. 같은 촬영 거리와 조명, 회보라색 배경의 2×2 초상화 아틀라스. 모두 동등하게 중립적인 표정이며 범인을 암시하는 연출 배제.

## 검증

`node --test tests/mystery*.test.cjs`는 단독 진행부터 엔딩까지, 오답 복귀, 저장 후 재접속, 필수 증언·단서 차단, 데이터 참조 무결성, 중복·마감 후 투표 거절을 확인한다. 실제 방송의 SDK 수신은 몽나 방송에서 별도로 확인해야 한다.
