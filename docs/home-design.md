# 몽나 홈 디자인

홈 화면을 몽나의 라벤더 색상으로 재구성했습니다. 참고 이미지에서는 정보가 잘 구분된 패널과 일정한 간격을 참고했으며, 창 모양·배경·장식·배치를 복제하지 않았습니다.

- 옅은 라벤더 바탕과 짙은 보라 계열 글자, 얇은 테두리와 절제된 그림자를 사용합니다.
- 메인 사진은 기존 관리자 설정 이미지 그대로 사용하며 이미지 전체를 볼 수 있도록 contain으로 표시합니다. 이미지가 없거나 불러오지 못하면 기존 몽나 자산을 사용합니다.
- 사진 옆에 방송 상태와 오늘의 일정을 모으고 아래에는 주간 일정, 클립·캐치 랭킹, 몽튜브, 바로가기를 배치합니다. 모바일은 세로 배치로 전환합니다.
- 홈 글꼴은 Pretendard Variable이며 v1.3.9로 고정된 jsDelivr 배포본을 사용합니다. font-display:swap과 시스템 한글 글꼴 대체를 지정했습니다. 관리자·OAuth 게임 페이지에 이 외부 글꼴을 추가하지 않습니다.
- 설정 편집·저장은 기존 관리자 API를 사용합니다. 홈에만 단순한 바로가기 라벨을 적용하며 다른 화면의 공용 메뉴 기본값은 유지합니다.
- 기존 홈의 방송 상태 요청이 수집용 `/api/soop` 결과에서 broad 배열을 찾고 있던 것을 방송 상태 전용 `/api/live`의 isLive를 읽도록 수정했습니다. 기존 수동 방송 중 표시도 함께 적용합니다.
- 캘린더의 분류·일정 데이터와 영상 랭킹은 앞선 구현을 사용합니다. 새로운 관리자 설정이나 데이터 이전은 없습니다.

검증은 `npm test` 82개, 운영 빌드, 변경된 홈·랭킹 코드 범위 TypeScript 검사를 사용합니다. 홈 테스트는 실시간 상태·일정·랭킹·링크와 관리자 설정 저장 요청을 확인합니다. 실사용 데이터 쓰기는 모의 API로 대체합니다.

## 홈 수정 사항

상단 소개 문구와 사진 아래 설명줄을 제거했습니다. 사진 옆 ‘오늘의 일정’은 팬카페 ‘방송 알람’ 최신 공지로 교체합니다. 주간 일정은 캘린더와 같은 색상 우선순위(일정 저장 배경색, 분류색, 호환 색상, 기본값)를 사용하고 일정 박스 전체를 칠합니다. 일정의 지정 글자색도 적용합니다.

`GET /api/broadcast-notice`는 네이버 카페 31747136의 방송 알람 게시판(5번)을 공개 게시판 API로 조회합니다. 기존 cafe2 ArticleList 주소는 403 오류를 반환하므로 현재 cafe-boardlist-api/v1 응답을 사용합니다. 2026-10-18 로그인 쿠키 없이 실제 공개 목록·작성자·게시판·본문 미리보기를 확인했습니다. 몽나의 공개 작성자 식별자, 정확한 카페·게시판, 공개/블라인드 여부를 검사하고 고정 공지 대신 작성 시각이 가장 최근인 일반 글을 표시합니다. 비공개 글은 표시하지 않습니다. 제목·요약은 HTML로 삽입하지 않고 텍스트로 출력하며, 글을 누르면 팬카페 원문으로 이동합니다.

서버·CDN은 약 1분 캐시하며 화면은 보이는 탭에서 2분 간격으로 다시 확인합니다. 오류를 빈 공지로 처리하지 않고 안내와 게시판 링크를 제공합니다. 로그인 정보나 환경변수는 필요하지 않습니다. 네이버의 공개 웹 API 변경 시 수집기 갱신이 필요합니다. 기존 다른 카페 게시판 수집 API는 이 작업에서 수정하지 않습니다.

추가 검증: 최신 글 선택·작성자/게시판 제한·공개 글만 표시·텍스트 처리·오류 UI·캘린더 배경색 적용을 포함해 총 82개 테스트를 수행합니다.
