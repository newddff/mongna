# 방셀 스튜디오 저장 API

- 화면: `newddff/mongna-bangsel-studio`, Cloudflare Pages.
- Pages Functions `/api/studio/*`는 고정된 이 서버의 `/api/bangsel/*`로 요청합니다. 쓰기 요청은 양쪽에서 Origin을 확인하고 관리자 쿠키를 검증합니다.
- 기존 `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, `FIREBASE_SERVICE_ACCOUNT`를 재사용합니다. 비밀값을 프런트엔드나 Cloudflare에 복사할 필요가 없습니다.
- 다른 도메인이므로 스튜디오에서 최초 한 번 별도 로그인합니다. 기존 팬페이지 관리자 비밀번호를 사용하고 장기 유지 쿠키를 발급합니다.
- 방셀 데이터: Firestore `mongna_bangsel_cards`. Admin SDK만 읽고 쓰며 익명 클라이언트의 컬렉션 접근은 차단되어야 합니다. 기존 컬렉션과 데이터는 변경하지 않습니다.
- 미디어: Firebase Storage `mongna-vod.firebasestorage.app`, `bangsel/` 경로. Firebase 콘솔에서 Storage가 생성되어 있고 서비스 계정에 파일 생성 권한이 있어야 합니다. 기존 Firestore 사용/결제 여부만으로 Storage 생성이 보장되지는 않습니다.
- 사진 최대 20MB, 영상 최대 100MB. 3MiB 조각으로 서버를 경유해 GCS resumable upload를 수행합니다. MIME 허용 목록과 관리자 인증, 서명된 1시간 업로드 상태를 확인합니다.
- 감상 URL은 128비트 무작위 ID를 사용하며 링크를 가진 사람이 로그인 없이 봅니다. 특정 SOOP 사용자에게만 제한하는 인증 기능은 아닙니다. 이름은 표시용입니다.
- 삭제하면 방셀 데이터와 감상 링크를 제거합니다. 복제 방셀과 같은 사진을 참조할 수 있으므로 미디어 파일을 자동 삭제하지 않습니다. 미사용 업로드 파일 정리는 별도 운영 작업입니다.
- 시청자는 URL의 `id`로 서버에서 저장된 데이터를 조회합니다. 브라우저 전용 blob URL은 저장할 수 없습니다. 저장되지 않은 수정본의 링크 복사는 비활성화됩니다.
- SOOP에서 외부 iframe을 허용하는지는 SOOP 편집기에서 별도 확인해야 합니다. 차단된다면 감상 URL 링크로 이용할 수 있습니다.

## 운영 확인

1. 스튜디오에서 기존 관리자 비밀번호로 로그인.
2. 사진 또는 영상을 업로드하고 저장. 다른 브라우저에서 감상 링크를 열어 재생 확인.
3. 페이지 재접속 후 제작한 방셀에서 수정, 재저장. 기존 링크에서 수정 반영 확인.
4. 삭제 후 기존 감상 링크가 404 안내를 보이는지 확인.

자동 검증은 테스트 데이터/모의 저장소를 사용합니다. 실제 계정으로 업로드하는 확인은 운영 설정 완료 후 필요합니다.
