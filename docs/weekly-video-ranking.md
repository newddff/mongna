# 주간 클립·캐치 조회수 랭킹

홈 화면에 클립과 캐치를 각각 TOP 5로 표시합니다. 현재 시각에서 최근 7일에 **등록된** 몽나 방송 영상의 **누적 영상 조회수**를 비교합니다. 일주일 동안 증가한 조회수 순위가 아니며 별도 과거 조회수 스냅샷을 저장하지 않습니다. 한국 시간으로 기간과 등록일을 표시합니다.

## 공개 영상 수집

SOOP 채널 페이지가 사용하는 공개 API `https://chapi.sooplive.com/api/pinktape8/vods/{clip|catch}/all`을 호출합니다. `orderby=reg_date`, `per_page=50`, 날짜 범위와 페이지 번호를 지정합니다. 2026-10-18 실제 응답에서 구조와 정렬·날짜 필터·페이지 이동을 확인했습니다. 다른 제작자의 계정으로 등록됐어도 몽나 방송에 연결된 클립·캐치가 포함됩니다. 다른 방송의 제목 검색·전체 SOOP 검색은 수행하지 않습니다.

- `ucc.file_type`이 정확히 `CLIP` / `CATCH`인 영상만 인정합니다. 길이나 제목으로 다시보기를 추측하지 않습니다.
- 재생 주소는 `title_no`를 사용합니다. `bbs_no`는 사용하지 않습니다.
- 조회수는 `count.vod_read_cnt`를 우선하며 없으면 `count.read_cnt`를 사용합니다. 0도 유효한 조회수입니다.
- `reg_date`는 한국 시간으로 해석합니다. 등록일·영상 종류·조회수가 확인되지 않는 데이터, 다른 채널 연결이나 삭제 표시 영상은 제외합니다.
- 같은 영상 번호는 중복 제거합니다. 조회수 동률이면 최신 등록 순입니다.
- 페이지를 이어 조회하되 최대 10페이지·총 20초로 제한합니다. 일시적인 통신·서버 오류는 남은 제한 시간 안에서 한 번 재시도합니다. 중간 실패·페이지 반복·상한 도달 시 `partial`을 표시해 전체 순위로 오인하지 않도록 합니다. 최초 수집 실패는 `error`로 표시하며 ‘영상 없음’으로 숨기지 않습니다.

이 주소는 공개 채널용 API이며 SOOP 개발자 인증 API의 안정성 보장이 있는 엔드포인트는 아닙니다. SOOP가 구조를 변경하면 수집기 갱신이 필요합니다. SOOP 로그인 토큰이나 별도 환경변수는 사용하지 않습니다.

## 갱신과 기존 주소

`GET /api/clips`는 두 분류의 결과·상태·기간을 반환합니다. 동시 요청은 하나의 수집을 공유합니다. 정상 결과는 서버와 CDN에서 약 5분 캐시하며 불완전·오류 결과는 CDN에 캐시하지 않고 프로세스 내에서만 30초 보관합니다. 화면은 보이는 탭에서 약 5분 간격으로 다시 조회하고 수동 새로고침도 제공합니다. 새로고침에도 캐시 유효 기간 내에는 같은 결과를 받을 수 있습니다.

기존 `GET /api/catch`는 같은 수집기의 캐치 결과를 `{ clips, status, period, updatedAt }`로 반환합니다. 두 분류 모두 수집 실패 시 `/api/clips`는 502를 반환합니다. 한쪽만 실패해도 나머지 순위는 볼 수 있습니다.

## 구플 일정

`src/lib/calendar-categories.ts`에 기본 분류와 색상을 공용으로 정의했습니다. `구플` 기본 색은 `#ec4899`이며 일정 추가·수정 선택과 카테고리 색상 설정에 표시합니다. 기존 저장 색상에 기본값을 합쳐 새 카테고리를 유지하고, 홈 일정에서도 같은 기본 색을 사용합니다. 일정 저장은 기존 관리자 검증 API를 사용합니다.
