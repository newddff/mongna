# 몽나 채팅 보드게임

`/streamer/minigames`에서 사목·오목·체스·장기를 선택합니다. SOOP 연결 하나를 공유하며, 선택한 게임만 채팅과 시간을 받습니다. 게임을 바꾸면 진행 중인 보드와 투표는 보존되고 타이머는 멈춥니다. 새로고침 시 대국은 초기화됩니다.

## 조작과 채팅

몽나는 보드를 클릭하고 달구는 채팅으로 투표합니다. 체스·장기는 출발 칸과 도착 칸을 차례로 클릭합니다. 좌표는 아래쪽이 1, 왼쪽이 A입니다.

| 게임 | 채팅 예 | 규칙 |
| --- | --- | --- |
| 사목 | `1` ~ `7` | 중력 적용, 가로·세로·대각선 4개 |
| 오목 | `H8` | 15×15 자유룰, 5개 이상, 삼삼·사사 금수 없음 |
| 체스 | `e2e4`, `e7e8n` | 캐슬링·앙파상·체크메이트·무승부·승격 적용. 승격 글자 생략 시 퀸 |
| 장기 | `a4a5`, `쉼`, `빅장` | 친선 규칙, 기물 이동·장군 회피·빅장·반복 적용 |

체스·장기 채팅은 `e2 e4`, `e2-e4`도 허용합니다. 한 투표에서 사용자당 첫 유효 입력만 받습니다. 불가능한 수는 받지 않습니다. 최다 득표를 실행하며 동률이면 몽나가 후보 버튼으로 선택합니다. 참여자가 없으면 기다리고 투표를 다시 열 수 있습니다. 수동 마감과 다음 투표 시간 설정을 지원합니다.

선공·후공은 새 대국에 적용합니다. 장기는 초·한 각각 마상 배치를 선택할 수 있습니다. 채팅 연결이 끊어지면 투표와 타이머를 멈춥니다.

## 장기 범위

친선 규칙이며 대회 점수제는 적용하지 않습니다. 포는 포를 다리로 쓰거나 잡을 수 없고, 마·상은 길목을 검사합니다. 궁성 대각선과 졸의 상대 궁성 이동을 적용합니다. 장군 상태에서 한수쉼은 불가능합니다. 빅장은 수락하거나 왕의 마주봄을 해소하며, 응수 뒤에도 마주보면 무승부입니다. 동일 국면 3회, 연속 한수쉼 2회, 양쪽 궁·사만 남은 경우 무승부입니다.

## 검증

`npm test`: 기존 SOOP 인증 25개, 게임 규칙·투표 22개, React UI 7개. UI는 중복 투표·동률·무투표·연결 중단·보드 클릭·게임 전환과 연결 공유를 검사합니다. `npm run build`로 운영 빌드를 확인합니다. 별도 Chromium 확인에서 1440px/390px 배치, 클릭·모의 SDK 채팅, 오류·가로 넘침 여부를 검사했습니다. 실제 SOOP 신규 게임 플레이는 운영 연결에서 추가 확인이 필요합니다.
